## 安装与开始使用

1. 保存其他软件中尚未保存的工作。
2. 打开 EXE，阅读[使用条款](legal/使用条款.txt)、[桌面隐私说明](legal/隐私说明.txt)及组件许可证，接受后按安装引导继续。
3. 安装后按引导操作，使用 Windows 的输入法切换功能（Win＋空格）选择 Mansur。
4. 普通打字不需要下载大模型。翻译、朗读按所选模式准备模型或在线服务；本地听写需准备识别模型。根据电脑环境选择，确认后再下载。约 398 MiB 的安装包不包含全部可选模型。
