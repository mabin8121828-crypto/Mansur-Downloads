一、适用范围与用户选择
本说明介绍相关数据的处理目的、种类、方式、保存位置及管理渠道。安装时确认已阅读本说明，不等于同意全部可选数据处理。
普通文字输入可独立使用。模型下载、在线服务、录音和浏览器网页对照分别按功能设置、主动操作及平台授权启用；拒绝或关闭这些功能，不影响普通文字输入。依法要求的专门告知或单独同意，包括涉及敏感个人信息或向境外提供个人信息的相应要求，不能由安装接受替代。
本说明对在线服务的一般介绍不替代依法需要的具体接收方告知、单独同意或其他法定手续。

二、文字输入与个人词库
为完成输入，程序在本机处理正在输入的拼音、字母、候选词及确认提交的文字，将确认结果写入当前应用的输入框。学习模式下，文字可先进入本机草稿，经用户确认后提交。写入输入框不等于操作聊天软件的发送按钮。
启用“记住常用字词”后，程序在本机保存已确认的字词、拼音及使用次数，用于调整候选结果。关闭此功能会停止新增记忆，已有记录仍保留；相关记录可通过个人词库功能管理、删除、导入或导出。
普通输入内容不会因安装协议的接受而获准发送至在线翻译服务。文字提交至其他应用后，该应用的后续处理适用其自身规则。

三、翻译、朗读与服务配置
本地模式使用本机模型处理本次请求的文字或音频。所需模型及运行文件准备完成后，相应本地功能可离线运行；模型下载、在线服务及第三方运行组件的网络活动不属于该离线处理范围。
在线翻译向设置中选定的服务地址发送待翻译文字及完成请求所需的提示；在线朗读向所选语音服务发送待朗读文字，并接收生成的音频。身份验证按服务接口要求提供相应凭证。服务配置和使用应结合具体提供方、接口地址、计费、保存规则及处理地域审慎选择；需要另行告知或取得同意的事项，应在相应处理前完成。
本地模式失败时，不自动改用付费 API。浏览器扩展不读取桌面应用管理的 API 密钥，也不将选中文字发送至 Mansur 自建服务器；桌面应用的在线处理仍按所选服务执行。
API 密钥通过 Windows 当前用户的数据保护机制加密保存在本机。密钥输入留空后保存，会保留原密钥；删除时，可在“模型与 API”中选择对应服务的“保存时删除此服务的密钥”，再保存并应用。加密措施不能消除全部风险，Windows 账户及服务凭证仍需妥善保管。
主动检查在线服务连接或获取在线服务的模型列表时，程序会向所选服务发起相应请求。此处“模型列表”指服务端提供的可用模型目录，不是浏览本地模型文件夹。

四、听写、跟读与录音
听写快捷键、麦克风按钮或跟读录音操作被主动触发后，相关功能开始处理录制声音及识别文字。本版听写和跟读识别使用所配置的本地识别模型。在线朗读发送待朗读文字，不因启用朗读而自动上传麦克风录音。
听写结果根据当前模式进入输入框或草稿。跟读识别结果用于练习及文字对照，不写入其他应用输入框。跟读录音在当前练习会话中临时保留供回听，取消练习、结束会话或关闭窗口时按程序流程清理，不自动加入收藏。异常退出、操作系统缓存或外部备份可能留下残留，不能据此承诺所有副本即时、完全删除。
用户可停止录音、取消练习或关闭相关功能。录制、提交或分享他人声音及私人内容前，应具备相应权限或其他合法处理依据。

五、划词、Word 及浏览器接入
整页翻译与划词学习分别开启。用户在具体网站主动开启“整页自动译成中文”后，扩展读取该页面可处理的可见文字并在本机分段翻译，刷新及动态内容变化时继续处理；输入框、密码框和可编辑区域等不参与整页翻译。整页翻译默认使用本地模型；用户可针对具体网站另行选择在线 API，并在开启前确认文字发送及可能计费的说明。在线模式将该网站待译文字分段发送给电脑端记住的翻译 API 服务，刷新和动态补译也可能产生调用费用；未配置相应模型或密钥时提示检查，不自动切换服务。两种模式均不在失败时擅自切换到另一种，不保存整页正文或译文历史。网站开关保存在浏览器本地；关闭整页翻译时恢复所记录的原文，并保留页面后续产生的有效变更。
划词工具、Word 右键和浏览器右键处理用户主动选择或粘贴的文字，用于本次翻译和学习；该操作不构成持续读取全部文档或浏览历史的授权。
浏览器划词学习默认不在网站启用。用户在具体网站主动开启并授予权限后，选中的英文词句可触发翻译、释义和按设置朗读；可通过网站开关关闭，或清空本页译文。普通输入框、密码框和可编辑区域不参与自动划词。扩展在浏览器本地保存网站开关和划词选项；用于定位译文的临时选区、页面信息及本地站点设置，另见对应扩展的隐私说明。
句子上下文默认关闭；用户选择开启时，本次有效选文所在的有限上下文可随请求用于释义或详细讲解。若选择在线翻译、释义或朗读服务，相应文字会发送给用户所选服务提供方。详细语法讲解的在线服务单独配置且默认关闭；配置后仅在用户主动请求详细讲解时，将相关选文和本次允许的上下文发送给所选服务提供方处理。选择 OpenRouter 时，该服务可在同一模型的不同推理提供方之间转发请求以应对限流或故障，所选文字、允许的上下文及审校候选可能由相关提供方处理；不同提供方的费用和数据处理规则可能不同。所选服务可能产生费用，具体处理及保留规则以该提供方说明为准。
本机接入和浏览器连接检查在本机处理浏览器种类、扩展及软件版本、时间、会话、安装位置及检查结果，用于核对连接归属。连接检查不读取网页选中文字；主动选择“试译一句”时，仅使用界面显示的固定样句验证翻译。
扩展安装、网站访问及 Windows 麦克风权限由相应平台管理，不能以安装接受替代。浏览器和平台自身的数据处理亦适用其各自规则。

六、收藏、复习与本地设置
用户主动收藏时，程序保存相应原文、译文、来源类别、备注、时间及复习状态，用于查看和复习。收藏不保存完整网页地址、浏览历史或整页内容；相关记录可在“我的收藏”中查看、删除、导入或导出。导出文件由用户自行保管。
个人词库与学习收藏分别保存。本版不提供云同步。软件偏好、所选模型、下载位置及接入选择等保存在本机，用于恢复使用设置；升级按既有设置保留相关配置，不因升级自动公开或上传这些资料。

七、下载服务与第三方运行组件
确认下载模型或所需文件后，程序连接相应托管或下载服务，在本机保存下载进度、文件及用于完整性校验的大小和摘要。下载服务交付文件时可能处理 IP 地址、请求时间、资源路径等网络请求信息，具体规则适用该服务说明。模型下载不以上传个人词库或收藏为条件。
部分功能依赖 Microsoft WebView2 等第三方运行组件。其安装、更新及自身数据处理适用相应提供方条款。本软件的本地处理说明不替代第三方运行组件的规则，亦不表示其全部操作均不联网。
选用境外服务可能涉及境外提供方处理请求数据。相应处理依法需要的具体接收方告知、权利渠道、单独同意及其他手续，应在处理前按适用要求完成，不能由本安装协议概括替代。不选用在线服务时，仍可使用普通输入及已准备完成的本地功能。

八、安装诊断与协议记录
为完成安装、更新、接入核对和故障排查，程序在本机保存软件版本、操作阶段、时间、耗时、结果、错误类型，以及相关安装路径、Windows 会话、账户标识或权限状态等诊断信息。部分路径可能包含 Windows 用户名，相关记录可能涉及个人信息，反馈前应核对内容并移除无关信息。
安装根目录的 Setup/AgreementAcceptance.json 保存最新一次本地协议接受记录，包括协议版本、合并文档 SHA256、接受时间、软件版本、接受状态及交互协议页来源。该记录不含姓名、账户标识、IP 地址或输入正文；更新时覆盖最新记录，不自动上传。
诊断与协议记录用于安装核对和修复，不自动发送给开发者。连接检查结果的有效期只决定其是否可用于判断当前连接，不表示文件到期后自动删除。未设自动清理的记录可能保留至后续结果覆盖或用户清理。

九、保存、删除、撤回与卸载
个人词库、收藏和配置在本机保存至用户主动删除、替换或清理。模型保存在选定位置；移除前应停止相关功能并保留所需文件，移除后相应功能可能需要重新配置或下载。
关闭词库记忆停止新增记录，不删除已有词库。关闭在线服务或切回本地停止后续相应调用，不能撤销服务提供方已经完成的处理；管理其保留数据，应同时使用该提供方的渠道。
卸载界面分别提供个人设置与 API 配置、个人词库、收藏与使用安装记录、专用目录内模型的删除选项，默认均不选中。所选类别的本机数据按界面说明清理；删除设置但保留词库或模型时，必要的资源位置记录仍保留。删除 API 凭证无需解密其内容。模型清理仅处理可以确认归属的本应用专用资源，自行指定的外部模型、导入原文件、用户导出的资料及其他账户的数据不擅自删除。原始许可证和来源材料按对应许可保留。仍被占用、未知或受保护的内容会明确提示，不承诺未经核实的所有副本即时完全清除；可能需要重启后继续卸载。卸载浏览器扩展不自动清除桌面数据。需要定位或进一步清理时，可联系 800693@QQ.com 获取说明。
不再使用可选功能时，可关闭对应开关、停止录音、撤销网站权限或删除服务密钥。撤回同意不影响撤回前基于同意已经进行的处理。依法确需继续保存或暂时无法删除的资料，应说明理由，并按适用要求限制后续处理。

十、客服资料与权利请求
用户主动通过客服邮箱发送问题时，开发者处理所提供的邮件地址、邮件内容及附件，用于回复和解决请求。相关资料按处理请求及必要后续事项所需保留，不用于无关营销。
有关开发者实际持有资料的查阅、复制、更正、删除、撤回同意、限制处理、解释说明或投诉，可通过 800693@QQ.com 提出。为防止错误删除或向他人披露，可能需要合理核实请求与资料的关系；核实时不应提交密码、验证码或 API 密钥。
纯本机数据由用户控制，客服不能仅凭邮箱远程读取或删除，将提供与软件版本相符的管理说明。未能立即满足请求时，应说明原因和可采取的处理方式。
开发者不出售个人数据，不将处理内容用于广告追踪、无关用户画像、信用评估或借贷。

本地整页翻译的可见上下文与专业增强（94版新增说明）

本地通用整页翻译可读取待译文字附近有限的可见原文，包括同一行、表头和相邻标签，用于区分短词含义。上下文与目标文字交给本机模型处理；输入框的值、可编辑区域、普通隐藏内容及表单不作为上下文。数学排版可使用有限的辅助语义节点来保留公式含义。页面文字、上下文与译文不写入浏览器持久存储。

专业增强默认关闭，由电脑端设置统一控制。开启后，由你选择一个专业领域，并决定是否使用已导入词库；Chrome和Edge跟随同一设置。词库及全局设置保存在本机，导入不修改原CSV文件；扩展只读取领域、是否就绪和术语数量，不读取完整词库或本地词库路径。存在词库或旧网站设置不会自动开启专业增强。保存设置后，请刷新已打开网页应用。

专业词库和本次新增的可见上下文字段仅用于本地整页翻译，在线API及划词翻译保持各自已有的数据规则；不会因为本地失败自动切换在线服务。安装包不包含你的个人词库、设置、翻译历史或模型。
