三、模型与在线服务
普通文字输入不要求下载模型或使用在线服务。翻译、朗读、听写及跟读功能可能需要相应模型或服务配置；模型可按功能提示下载或选择已有文件，也可取消或稍后配置。下载大小、运行速度及内存占用取决于所选模型和设备环境。
模型权重、运行组件及其他下载材料适用其来源规定的许可证。用于特定用途前，应核对相应使用条件；本软件的 MIT 授权不改变第三方模型的使用或再分发条件。

四、安装、升级与卸载
安装程序向选定的程序位置写入文件，注册输入组件，并按安装选项准备当前账户的配套接入。所需系统权限由 Windows 管理。浏览器扩展的安装及网站访问授权仍由浏览器管理。
卸载时，程序文件及经核验的旧版本程序文件按屏幕所示范围清理。个人设置和 API 配置、个人词库、收藏与使用安装记录、本应用专用目录内的模型分别提供删除选项，默认保留；只有主动勾选的类别才进行对应清理。保留词库或模型时，软件会保留恢复这些资源所需的位置记录。自行指定的外部或共享文件不因卸载自动删除。文件被占用或归属无法核实时，卸载会说明剩余内容及后续步骤，不将尚未完成的清理显示为已完成。共享的 Microsoft WebView2 Runtime 等系统组件不随本软件卸载一并删除。
安装或升级前，应保存其他应用中正在编辑的工作。安装未完成时，以安装程序及结果记录显示的状态为准，不应将已写入部分程序文件理解为安装成功。
