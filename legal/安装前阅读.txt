一、先说明你的选择
本说明介绍数据处理的目的、范围、位置、保存和管理方式。安装时的接受仅涉及安装使用条款及已披露的必要处理，确认阅读本说明不等于授权全部可选处理。
普通打字与模型、在线服务、录音和浏览器自动对照是不同功能。你可以不配置或关闭可选功能，继续普通打字。在线调用须按你的服务选择和实际请求进行；录音须主动开始；浏览器站点权限须另行确认。安装接受不能代替法律要求的单独同意，尤其不能替代向境外提供个人信息等事项的专门告知与单独同意。

二、普通输入与个人词库
为完成输入，程序在本机处理你正在输入的拼音、字母、候选词和确认提交的文字，并把确认的结果放入当前应用输入框。学习模式开启时，文字可先进入本机草稿，由你确认提交；提交文字不会替你点击聊天软件的发送按钮。
启用“记住常用字词”时，程序在本机记录确认过的字词、拼音和使用次数，用于调整候选结果。关闭该功能会停止新增记忆，原有记录保留。你可以在个人词库功能中管理、删除、导入或导出相应记录。
普通打字不会因接受本安装文件而被授权发送给在线翻译服务。你在其他应用中提交文字后，该应用如何处理内容，仍取决于其自身规则。

三、翻译、朗读和在线配置
本地模式使用电脑上的模型处理本次请求的文字或音频。模型和所需文件准备完成后，相应本地功能可以离线使用；这不表示软件的下载、在线服务或第三方运行组件永远不联网。
在线翻译会将你请求翻译的文字及完成该请求所需的提示发送至设置中选定的服务地址；在线朗读会将待朗读文字发送至所选语音服务，并接收生成的音频。服务认证时会按接口要求向所选服务提供相应凭证。请在配置和使用前核对提供方、接口地址、费用、保存规则和适用地域。
本地模式不会在失败后自动改用付费 API。Mansur 的浏览器扩展不读取桌面应用管理的 API 密钥，也不把选中文字发送到 Mansur 的服务器。
API 密钥按当前 Windows 用户加密保存在本机。密钥留空保存会保留原密钥；如需删除，请在“模型与 API”中选择对应服务的“保存时删除此服务的密钥”，再保存应用。加密不表示任何设备或账户环境下都绝对安全，请保护好 Windows 账户和服务凭证。
你主动检查服务连接或读取模型目录时，程序也会按所选服务发出相应请求；不应把这些检查误认为完全离线操作。

四、听写、跟读与录音
只有你主动使用听写快捷键、麦克风按钮或跟读录音操作时，相关功能才开始录音，并处理录制声音及识别文字。本版听写与跟读识别使用所配置的本地识别模型；在线朗读发送的是待朗读文字，不因开启朗读而自动上传麦克风录音。
听写结果按当前模式进入输入框或草稿。跟读只用于练习，不像听写那样写入其他应用输入框。跟读录音临时保存在当前会话中，结束或关闭后按程序流程清理，不自动加入收藏。异常退出、操作系统或备份工具的行为不在此处被承诺为完全自动清除。
你可以停止录音、取消练习或关闭相关功能。请不要录制或提交无权处理的他人声音、私人内容或敏感信息。

五、划词、Word 和浏览器接入
划词工具、Word 右键和浏览器右键处理你主动选择或粘贴的文字，用于本次翻译和学习，不代表允许持续读取全部文档或浏览历史。
浏览器网页对照默认不在网站开启。你在相应网站主动开启并授权后，选择英文会请求翻译；可关闭网站开关或清空本页译文。当前页面为定位译文而使用的临时选区及页面信息、网站开关的本地保存，另见对应扩展隐私说明。
本机接入和浏览器连接检查会处理浏览器种类、扩展及软件版本、时间、会话、安装归属位置和检查结果，避免连接到错误版本或位置；连接检查不读取网页选文，只有主动“试译一句”才使用显示的固定样句进行翻译。
网站访问权、扩展安装权及 Windows 麦克风权限由相应平台管理，不能用本次安装接受替代。浏览器及平台本身的处理还适用各自隐私规则。

六、收藏、复习与本地配置
只有你主动收藏时，程序才保存相应原文、译文、来源类别、备注和复习状态。收藏不保存网页完整地址、浏览历史或整页内容。你可以在“我的收藏”查看、删除、导入或导出；导出文件由你自行保管。
个人词库与学习收藏是不同数据区。本版不提供云同步。软件偏好、选用模型、下载位置和接入选择等保存在本机，用于恢复你的使用设置；升级会沿用这些设置，而不是自动替你公开或上传。
